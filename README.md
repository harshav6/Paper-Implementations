# Research Paper Implementations

A collection of research paper implementations in PyTorch, focused on understanding and reproducing the core ideas from the original papers.

## Implementations

| Paper | Implementation |
|---|---|
| YOLOv1 — You Only Look Once | [YOLOv1](./YOLOv1) |

## Goals

- Implement research papers from scratch using PyTorch
- Understand the architectures and algorithms behind them
- Reproduce the key ideas described in the original papers
- Experiment with training and evaluation

## Papers

### YOLOv1

**Paper:** You Only Look Once: Unified, Real-Time Object Detection

YOLOv1 is an object detection model that formulates object detection as a single regression problem, directly predicting bounding boxes and class probabilities from an image.

See the [`YOLOv1`](./YOLOv1) directory for the implementation.
